# Caderno da Roça

Aplicativo para o produtor rural registrar a produção e saber quanto sobra em cada atividade.
Funciona sem internet e guarda os dados apenas no celular de quem usa.

**Acesse:** https://pedrogoncalve-cpu.github.io/caderno-da-roca/
